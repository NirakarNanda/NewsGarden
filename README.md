# NewsGarden

A scheduled multi-agent AI newspaper system with a separate frontend and backend.

## V1 Architecture

Frontend:
- Next.js
- TypeScript
- Tailwind CSS
- GSAP
- 2D illustrated/isometric campus UI

Backend:
- Node.js
- TypeScript
- Express
- MongoDB
- Multi-agent orchestration
- Scheduled newspaper workflows

Shared:
- TypeScript types and constants

Core flow:

Scheduler → Brain → Discovery → Research → Editorial → Visual → Design → Quality → Approval → Publish

The campus UI visualizes real agent state. It is not a chatbot and does not use fake activity as the primary interaction model.
